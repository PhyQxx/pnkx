# pnkx-ui DESIGN.md

## 1. 视觉主题与氛围

pnkx-ui 应该像一个安静、清爽、可长期使用的生活工作台。它既要支撑系统管理、监控、表格、配置等高密度后台任务，也要照顾博客、记账、日记、笔记、纪念日、聊天等偏个人生活的模块，所以整体气质不能太冰冷，也不能变成营销页。

最终方向为：**轻暖生活工作台**。

- 核心感受：明亮、安静、有秩序、友好，适合每天打开使用。
- 表面系统：浅灰蓝应用背景、白色工作面板、克制边框、轻量阴影。
- 产品性格：实用后台系统中带一点生活工具的温度。
- 信息密度：中高密度。表格、筛选、表单保持紧凑、可快速扫描。
- 装饰方式：避免装饰圆球、大面积氛围渐变、营销式 hero。用语义色、小图标、模块徽标表达个性。
- 动效原则：快速、功能性强，hover 用来确认可操作性，不做夸张表演。

## 2. 颜色体系与角色

使用蓝灰中性色作为底盘，主操作使用清晰蓝色。模块色只用于小面积识别，不成为整页主题色。

### 基础色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--pnkx-bg` | `#f5f8fc` | 主应用背景 |
| `--pnkx-bg-soft` | `#eef4fb` | 次级背景、弱分区、非激活表面 |
| `--pnkx-surface` | `#ffffff` | 卡片、表格、面板、弹窗 |
| `--pnkx-surface-muted` | `#f8fafc` | 表头、筛选区、嵌套区域 |
| `--pnkx-border` | `#dfe7f0` | 主要边框 |
| `--pnkx-border-soft` | `#edf2f7` | 弱分割线 |

### 文本色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--pnkx-text` | `#1f2937` | 主文本、标题 |
| `--pnkx-text-secondary` | `#667085` | 次级文本、标签、表格辅助信息 |
| `--pnkx-text-muted` | `#98a2b3` | 提示、占位、禁用文本 |
| `--pnkx-text-inverse` | `#ffffff` | 深色或主色背景上的文本 |

### 操作与状态色

| Token | 色值 | 用途 |

### 模块强调色

以下颜色只用于小面积图标块、标签、图表辅助色、空状态插画。

| 模块 | 强调色 |
| --- | --- |
| 博客 / 文章 | `#8b5cf6` |
| 记账 | `#22c55e`，另一方向金额可配合 `#ef4444` |
| 笔记 / 日记 | `#f59e0b` |
| 纪念日 / 提醒 | `#ec4899` |
| 聊天 / AI | `#06b6d4` |
| 监控 / 系统 | `#64748b` |
| 文件 / 媒体 | `#6366f1` |

不要让任何一个模块强调色支配整个应用。pnkx-ui 的整体观感仍应是蓝灰、白色和主蓝色。

## 3. 字体规则

使用系统字体，保证中文和英文都稳定清晰。

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
  "Hiragino Sans GB", "Microsoft YaHei", Arial, sans-serif;
```

推荐字号层级：

| 场景 | 字号 | 字重 | 行高 |
| --- | --- | --- | --- |
| 页面标题 | 22px | 650 | 1.3 |
| 分区标题 | 18px | 650 | 1.35 |
| 卡片标题 | 15px | 600 | 1.4 |
| 正文 / 表单 / 表格 | 14px | 400 | 1.55 |
| 表头 / 标签 | 13px | 600 | 1.4 |
| 元信息 / 提示 | 12px | 400 或 500 | 1.4 |

规则：

- 字间距使用 `0`，不要使用负字距。
- 不使用随视口宽度变化的字号。
- 表单标签和表格表头保持紧凑。
- 后台面板内部不要使用 hero 级大标题。

## 4. 组件样式

### 按钮

主按钮使用纯色 `--pnkx-primary`。只有当按钮是当前区域的主要动作时，才添加轻微阴影。次级按钮使用白底边框。危险按钮使用红色，但不应比主操作更抢眼。

- 圆角：8px。
- 高度：表格工具栏 32px，表单按钮 36px，弹窗主操作 40px。
- 图标按钮优先使用 Element Plus 图标。
- 表格内文字按钮应紧凑，hover 时出现柔和背景。

### 卡片与面板

卡片是工作表面，不是装饰元素。

- 圆角：8px。
- 边框：`1px solid --pnkx-border`。
- 阴影：无阴影或极轻阴影。优先用边框建立层级。
- 头部：垂直内边距 14-16px。
- 内容：根据密度使用 16-20px 内边距。

不要把装饰性卡片再嵌套进其他卡片。重复条目可以是卡片，整页分区应尽量使用无框布局或面板。

### 表格

表格是 pnkx-ui 的核心模式，要保持高效、紧凑、易扫描。

- 表头背景：`--pnkx-surface-muted`。
- 表头文字：13px、600、`--pnkx-text-secondary`。
- 行高：根据内容控制在 44-52px。
- hover 背景：`#f1f7ff`。
- 选中行：主色浅背景，必要时加左侧强调线。
- 空表格状态：居中、小图标、一句直接说明。
- 操作列要对齐，避免按钮文字尴尬换行。

### 表单与筛选区

搜索和筛选表单应像紧凑的命令面板。

- 筛选块使用白色表面、边框、8px 圆角、16px 内边距。
- 横向筛选项在小屏幕下自然换行。
- 字段较多的弹窗表单优先使用顶部标签。
- 输入框圆角 8px，focus ring 使用 `0 0 0 3px rgba(37, 99, 235, 0.12)`。

### 导航

侧边栏是稳定的应用导航轨道，不应是厚重的深色块。

- 展开宽度：220px。
- 折叠宽度：64px。
- 背景：白色或接近白色，右侧使用柔和边框。
- 激活项：主色浅背景、主色文字，可选 3px 左侧强调线。
- 图标尺寸统一为 16-18px。
- Logo 区保持紧凑、清爽。

顶部导航是轻量命令栏：

- 高度：52px。
- 白色表面，底部边框。
- 左侧面包屑，右侧搜索、通知、用户操作。
- 避免高饱和渐变和过大的头像处理。

标签栏应像浏览器工作区标签：

- 高度：34-38px。
- 激活标签：主色浅背景、主色边框、主色文字。
- 非激活标签：白色表面、柔和边框。

### 弹窗与抽屉

- 圆角：10px。
- 头部和底部使用清晰分割线。
- 内容内边距：20-24px。
- 除非内容是表格、预览或编辑器，否则避免过宽弹窗。
- 加载状态应保持布局稳定，不造成内容跳动。

### 空状态、加载与错误状态

空状态要直接、有用。

- 使用简单图标或现有 `svg-icon`。
- 一句短标题，可附加一条提示。
- 系统管理模块避免过度俏皮的文案。

错误页可以更有温度，但必须提供明确的返回动作。

## 5. 布局原则

### 全局应用框架

使用一致的应用框架：

- 桌面端侧边栏固定。
- 主内容容器使用 `--pnkx-bg`。
- 内容页桌面端 padding 为 24px，平板为 16px，移动端为 12px。
- 无论是否启用标签栏，固定头部的偏移都必须稳定。

### 页面模式

按工作流选择页面模式：

1. 高密度管理页：筛选面板、工具栏、表格、分页。
2. 内容管理页：需要选择和预览时使用列表 / 详情分栏。
3. 仪表盘页：响应式网格、紧凑指标卡、一到两个大型运营面板。
4. 编辑器页：全宽编辑表面，搭配固定或粘性操作栏。
5. 聊天 / AI 页：会话区域加紧凑的会话或上下文侧栏。

不要强行把所有页面都改成卡片网格。界面应优先服务高频后台操作。

### 间距体系

使用 4px 基础间距：

| Token | 数值 |
| --- | --- |
| `--space-1` | 4px |
| `--space-2` | 8px |
| `--space-3` | 12px |
| `--space-4` | 16px |
| `--space-5` | 20px |
| `--space-6` | 24px |
| `--space-8` | 32px |

## 6. 深度与层级

优先使用清晰边框、小阴影和稳定层级。

| 层级 | 用途 | 阴影 |
| --- | --- | --- |
| 0 | 应用背景 | 无 |
| 1 | 表格、卡片、筛选面板 | `0 1px 2px rgba(16, 24, 40, 0.04)` |
| 2 | Popover、下拉菜单、hover 卡片 | `0 8px 24px rgba(16, 24, 40, 0.10)` |
| 3 | 弹窗、抽屉 | `0 18px 48px rgba(16, 24, 40, 0.18)` |

hover 位移要小，例如 `translateY(-1px)`。后台工具里不要使用大幅弹跳或旋转动效。

## 7. Do 与 Don't

Do：

- 保持高密度后台工作流可快速扫描。
- 使用统一 token，避免每个页面单独造一套颜色。
- 让表格、表单、弹窗在不同模块中保持一致。
- 模块强调色只做小面积识别。
- 遵循现有 Vue 和 Element Plus 模式，除非局部模式明显影响体验。
- 明确设计响应式状态。

Don't：

- 不要在应用框架内部创建营销页 hero。
- 不要使用装饰圆球、渐变光斑或 bokeh 背景。
- 不要把每个页面都做成装饰性卡片墙。
- 不要让紫蓝渐变成为主要视觉身份。
- 不要把所有控件都做成大圆角胶囊。
- 不要让文字溢出按钮、标签、表格操作列或卡片。
- 不要把重要表格操作藏在没有 tooltip 的不明确图标里。

## 8. 响应式行为

断点：

- 桌面端：`>= 1200px`，完整侧边栏和高密度表格。
- 平板端：`768px - 1199px`，侧边栏可折叠，筛选项换行。
- 移动端：`< 768px`，侧边栏变为抽屉，页面 padding 收紧，工具栏操作可分组。

规则：

- 最小触控目标为 36px，移动端优先 40px。
- 必要列较多的表格允许横向滚动。
- 筛选表单应先换行或堆叠，不要溢出。
- 移动端弹窗宽度上限为 `calc(100vw - 32px)`。
- 固定快捷操作不能遮挡分页或主要提交按钮。

## 9. Agent Prompt Guide

构建或改造 pnkx-ui 页面时，使用以下提示：

> 按 DESIGN.md 中的“轻暖生活工作台”风格构建这个 pnkx-ui 页面。使用蓝灰应用背景、白色带边框工作表面、紧凑 Element Plus 控件、8px 圆角、克制阴影、主蓝色操作，以及只用于小面积语义强调的柔和模块色。保留后台效率：筛选、表格、分页、弹窗应保持密集、稳定、可预测。避免 hero 布局、装饰圆球、重渐变、嵌套卡片和过大字体。

快速颜色参考：

- 背景：`#f5f8fc`
- 表面：`#ffffff`
- 边框：`#dfe7f0`
- 主文本：`#1f2937`
- 次级文本：`#667085`
- 主色：`#2563eb`
- 主色浅背景：`#dbeafe`
- 成功：`#16a34a`
- 警告：`#d97706`
- 危险：`#dc2626`

实现优先级：

1. 让 `design-tokens.scss` 与本文档对齐。
2. 更新全局 Element Plus 样式覆盖。
3. 现代化应用框架：侧边栏、顶部栏、标签栏、主内容区。
4. 重做登录页和首页仪表盘，作为视觉锚点。
5. 用全局模式统一表格、表单、弹窗页面。
6. 最后再精修高价值业务模块。
