<h1 align="center" style="margin: 30px 0 30px; font-weight: bold;">Pnkx-UniApp v1.0.0</h1>
<h4 align="center">基于UniApp开发的轻量级移动端框架</h4>

## 平台简介

Pnkx App 移动解决方案，采用uniapp框架，一份代码多终端适配，同时支持APP、小程序、H5！

## 技术栈

- **框架**: UniApp + Vue 2
- **UI**: uview-ui
- **状态管理**: Vuex
- **开发工具**: HBuilderX

## 主要功能

- 博客阅读：文章、相册、留言
- 生活管理：记账、待办、纪念日
- 情侣功能：情侣卡片、经期记录
- AI 智能助手：语音/文字交互
- 用户系统：登录、个人中心
